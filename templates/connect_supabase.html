Supabase Setup Guide:
  1. Go to your Supabase Dashboard
  2. Select your project
  3. Go to Settings → API
  4. Copy the Project URL and anon public key
  5. Go to Settings → Database to find your database password
Don't have a Supabase project?

You can create a free Supabase account and project:

  1. Visit supabase.com
  2. Click "Start your project"
  3. Sign up with GitHub or email
  4. Create a new organization and project
  5. Use the default database or create your own tables

Supabase offers a generous free tier for development and testing.
